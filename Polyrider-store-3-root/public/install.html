Install PolyRider in Chrome

You need Google Chrome on a Windows PC or a Mac, the PolyRider ZIP from the download page, and your license key. Phones and tablets can't run Chrome extensions.

A ZIP file can't be installed by clicking it. You first unzip (extract) it, then point Chrome at the folder inside that has manifest.json.
  1. Download the ZIP from the download page. It goes to your Downloads folder.
  2. Extract it: right-click the ZIP → Extract All… → Extract. You get a folder named like PolyRider-BTC-5m-v4.3.0.
  3. Move that folder somewhere permanent, e.g. Documents. Chrome runs PolyRider from this folder, so don't delete or rename it later.
  4. Open Chrome, type chrome://extensions in the address bar and press Enter.
  5. Turn on Developer mode (switch in the top-right corner).
  6. Click Load unpacked and select the PolyRider folder — the one that has manifest.json directly inside it — then click Select Folder.
  7. Optional: click the puzzle-piece icon in Chrome's toolbar and the pin next to PolyRider BTC 5m to keep it visible.
  8. Open polymarket.us, log in, and press F5 to refresh. The PolyRider panel appears bottom-left. Enter your license key if it asks, then press Activate.

Updating to a new version

When a new version is out, PolyRider shows a green "update available" note on polymarket.us. Updates are not installed automatically:

  1. Download the new ZIP from the download page (same email + key) and extract it.
  2. Copy the new files into your existing PolyRider folder, replacing the old ones. (Keeping the same folder keeps your settings and license.)
  3. On chrome://extensions, click the round reload ⟳ arrow on the PolyRider card, then refresh polymarket.us.

Troubleshooting

  • "Manifest file is missing" — you picked the wrong folder. Choose the folder that has manifest.json directly inside (not the ZIP, and not a folder above it).
  • No panel on polymarket.us — make sure PolyRider is switched on in chrome://extensions, then refresh the page.
  • Chrome asks about developer-mode extensions when it starts — you can keep PolyRider enabled. You never need to turn off antivirus or any Chrome security setting.
  • "Load unpacked" is missing or blocked — your Chrome is managed by a school or company. Use a personal computer or personal Chrome profile.
  • "Active on another computer" — one license works on one computer at a time. After a computer change it moves automatically after 24 hours, or email us to move it now.
  • First activation is slow — the license server can take up to a minute to wake up. Just wait.
